# File Protocol — [YOUR WORLD] Vault

## Before Editing
- Always Read a file before editing it — never assume current content.
- A lore change typically ripples: `CHARACTERS.md` → `TIMELINE.md`, `FACTIONS.md`.
- After any lore decision: update the source file AND `Lore/Lore_Audit.md` (if it exists).

## Lore Navigator Sync
- `Lore Navigator/index.html` is a single-file app co-maintained by Claude and Gemini.
- When updating any `.md` lore file, also update the matching entry in the `LORE` object inside `index.html`.

## Obsidian Conventions
- Cross-references use `[[WIKI_LINK]]` format — maintain when editing.
- Open questions tracked as `- [ ]` checkboxes; resolved as `- [x]`.
- Character design files live in `Book 1/Character Design/` (create this folder when needed).

## Co-writer Protocol
- If the story has a co-writer, tag lore corrections: "co-writer should update X."
